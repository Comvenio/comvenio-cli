# ACTION_NOT_LISTED — Diese Action steht für deine Verbindung gerade nicht zur Verfügung.

## Bedeutung

Diese Action steht für deine Verbindung gerade nicht zur Verfügung.

## Typische Ursachen

- Die Action fehlt in der Liste der für diese Verbindung freigegebenen Actions.
- Direkt nach einer neuen Version kann das bis zu einer Minute so bleiben.

## Lösung

1. Prüfen, ob die Action gelistet ist: `comvenio action list`
2. Nach einer neuen Version eine Minute warten und wiederholen.
3. Fehlt sie weiterhin, als Wunsch über das Issue-Formular melden.
