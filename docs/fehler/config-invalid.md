# CONFIG_INVALID — Die Anfrage konnte nicht zugeordnet werden.

## Bedeutung

Die Anfrage konnte nicht zugeordnet werden.

## Typische Ursachen

- Angaben zur Verbindung sind unvollständig.
- Angaben zur Verbindung sind ungültig.

## Lösung

1. Neu anmelden: `comvenio login`
