# UPLOAD_NOT_ENABLED — Datei-Upload ist in diesem Verein/auf diesem Server noch nicht eingeschaltet.

## Bedeutung

Datei-Upload ist in diesem Verein/auf diesem Server noch nicht eingeschaltet.

## Typische Ursachen

- Comvenio bietet das Hochladen vom eigenen Rechner (`comvenio action call cai.data.06.upload --file …`) für deine Verbindung noch nicht an.
- Das Hochladen ist vorübergehend abgeschaltet.

## Lösung

1. Die Datei in der Web-App hochladen.
2. Später denselben Befehl erneut versuchen.
