# UNKNOWN_ERROR — Ein unerwarteter Fehler ist aufgetreten.

## Bedeutung

Ein unerwarteter Fehler ist aufgetreten.

## Typische Ursachen

- Für diesen Fall gibt es noch keine Beschreibung.

## Lösung

1. Als Fehlerbericht über das Issue-Formular im Repository melden.
2. Die ausgegebene Anfrage-ID dabei angeben.
3. Mit `COMVENIO_DEBUG=1` liefert ein erneuter Aufruf zusätzlich den Stack für den Bericht.
