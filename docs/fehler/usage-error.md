# USAGE_ERROR — Der Befehl ist so nicht ausführbar.

## Bedeutung

Der Befehl ist so nicht ausführbar.

## Typische Ursachen

- Ein Argument oder eine Option fehlt.
- Argumente passen nicht zusammen.
- Ein Wert hat das falsche Format.

## Lösung

1. Hilfe zum Befehl ansehen: `comvenio --help`
2. Aufruf entsprechend korrigieren.
