# UPLOAD_NOT_ENABLED — File upload is not yet enabled for this club/on this server.

## Meaning

File upload is not yet enabled for this club/on this server.

## Typical causes

- Comvenio does not yet offer uploads from your own computer (`comvenio action call cai.data.06.upload --file …`) for your connection.
- Uploading is temporarily switched off.

## Solution

1. Upload the file in the web app.
2. Try the same command again later.
