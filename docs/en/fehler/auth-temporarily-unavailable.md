# AUTH_TEMPORARILY_UNAVAILABLE — The sign-in could not be verified right now.

## Meaning

The sign-in could not be verified right now.

## Typical causes

- Verifying the sign-in was briefly unavailable at the moment of the call.
- This only affects the check, not the sign-in itself.

## Solution

1. Wait a moment.
2. Repeat the same command.
