# USAGE_ERROR — The command cannot run like this.

## Meaning

The command cannot run like this.

## Typical causes

- An argument or an option is missing.
- Arguments do not fit together.
- A value has the wrong format.

## Solution

1. See the command's help: `comvenio --help`
2. Correct the invocation accordingly.
