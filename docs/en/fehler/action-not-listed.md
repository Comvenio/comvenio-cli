# ACTION_NOT_LISTED — This action is currently not available for your connection.

## Meaning

This action is currently not available for your connection.

## Typical causes

- The action is missing from the list of actions enabled for this connection.
- Right after a new release this can last up to a minute.

## Solution

1. Check whether the action is listed: `comvenio action list`
2. After a new release, wait a minute and try again.
3. If it is still missing, report it as a request through the issue form.
