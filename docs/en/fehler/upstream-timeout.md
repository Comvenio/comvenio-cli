# UPSTREAM_TIMEOUT — Comvenio did not answer in time.

## Meaning

Comvenio did not answer in time.

## Typical causes

- A read request exceeded the time limit.
- Nothing was changed by it — only reading was affected.

## Solution

1. Repeat the same command safely.
