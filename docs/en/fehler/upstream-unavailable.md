# UPSTREAM_UNAVAILABLE — Comvenio is currently unavailable.

## Meaning

Comvenio is currently unavailable.

## Typical causes

- The responsible part of Comvenio did not return a valid answer.

## Solution

1. Wait a few minutes.
2. Repeat the same command.
