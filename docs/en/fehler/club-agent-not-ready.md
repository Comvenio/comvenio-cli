# CLUB_AGENT_NOT_READY — The club agent is not set up for your club yet.

## Meaning

The club agent is not set up for your club yet.

## Typical causes

- An administrator of the club has not set up the club agent in the web app yet.

## Solution

1. Ask an administrator of the club to set up the club agent in the web app.
2. In the meantime, see the available commands: `comvenio agent --help`
